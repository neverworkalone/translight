Translight · 빛번역

자주 가는 사이트를
자동으로 번역하기

고급 설정에 사이트의 hostname을 등록하면 해당 사이트에 방문할 때 Translight가 자동으로 번역을 시작합니다.

사이트 등록하기

  1. 설정 페이지에서 고급 설정을 엽니다.
  2. 자동 번역 사이트 입력란에 hostname을 한 줄에 하나씩 적습니다.
  3. 저장을 누르고 등록한 사이트로 이동합니다.
입력 예시 example.com news.example.org docs.example.net

URL 전체를 입력해도 hostname만 저장됩니다. 프로토콜, 경로, 포트, 앞의 www.는 정리되며 중복되거나 잘못된 값은 제외됩니다. 등록한 도메인의 하위 도메인도 자동 번역 대상에 포함됩니다.

두 가지 동작 옵션

OFF
같은 사이트 자동 번역

직접 번역한 뒤 같은 출처의 다른 페이지로 이동했을 때 번역을 이어 갑니다. 기본값은 꺼져 있습니다.

OFF
페이지 제목 번역

브라우저 탭에 표시되는 페이지 제목을 함께 번역합니다. 기본값은 꺼져 있습니다.

자동 번역을 잠시 끄기

자동 번역으로 열린 페이지에서도 활성 아이콘을 클릭하면 현재 페이지의 번역을 끌 수 있습니다. 원문이 복원되고, 아이콘은 대기 상태로 돌아갑니다. 다시 번역하려면 아이콘을 한 번 더 클릭하세요.

참고 자동 번역 사이트 목록을 비워 두면 등록된 사이트 자동 번역은 사용하지 않습니다. 수동 번역은 언제든지 툴바 아이콘으로 시작할 수 있습니다.
