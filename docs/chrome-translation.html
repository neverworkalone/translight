Translight · 빛번역

Chrome 번역 모델
준비하기

Translight는 Chrome에 내장된 Translator API를 사용합니다. 번역 모델은 기기에서 실행되며, 페이지 내용을 외부 번역 서버로 보내지 않습니다.

영어 → 한국어 모델이 기기에 없으면 첫 번역을 시작할 때 자동 다운로드가 시작됩니다. 페이지가 길거나 처음 설치한 직후에는 다운로드와 번역에 수십 초가 걸릴 수 있습니다.

모델을 미리 다운로드하는 방법

  1. Translight의 설정 페이지를 엽니다.
  2. 번역 서비스에서 Chrome 내장 번역과 영어 → 한국어 모델의 상태를 확인합니다.
  3. 상태가 다운로드 필요라면 다운로드를 누르고 완료될 때까지 기다립니다.
  4. 상태가 사용 가능으로 바뀌면 설정을 저장하고 웹페이지에서 번역을 시작합니다.
영어 → 한국어사용 가능

모델이 준비되면 다음 번역부터 다운로드를 기다리지 않고 바로 시작합니다.

다운로드 중에는 어떻게 하나요?

툴바 아이콘의 안내와 설정 페이지의 진행 상태를 확인하면서 기다려 주세요. 다운로드가 끝나기 전에 아이콘을 여러 번 누르면 같은 작업을 다시 시작하거나 오류 상태가 보일 수 있습니다.

다운로드가 실패했다면 설정 페이지의 다시 시도를 누르세요. 계속 문제가 생기면 Chrome의 온디바이스 번역 관리 화면에서 en-ko 모델을 삭제한 뒤 다시 설치할 수 있습니다.

chrome://on-device-translation-internals

사용할 수 없는 경우

Chrome Translator가 지원되지 않는 환경에서는 모델 상태가 사용 불가로 표시됩니다. 이 경우 Chrome을 최신 버전으로 업데이트하고 데스크톱 환경에서 다시 확인해 주세요.
