Translight · 빛번역

영어 페이지를
한국어로 번역하기

Translight는 원문을 지우지 않고 번역문을 함께 표시합니다. 페이지의 흐름을 유지하면서 영어 문장을 한국어로 확인할 수 있습니다.

처음 사용하는 순서

  1. 영어 웹페이지를 엽니다. 번역할 페이지에서 브라우저 툴바의 Translight 아이콘을 찾습니다.
  2. T 아이콘을 클릭합니다. 아이콘이 번역 중 상태로 바뀌고, 보이는 영역부터 번역이 시작됩니다.
  3. 모델 다운로드가 필요하면 기다립니다. 첫 사용에는 Chrome의 영어 → 한국어 번역 모델을 내려받는 시간이 걸릴 수 있습니다.
  4. 번역문을 원문과 함께 읽습니다. 긴 페이지도 화면에 가까운 내용부터 처리한 뒤 나머지 내용을 이어서 번역합니다.

아이콘으로 상태 확인하기

T
대기번역을 시작할 수 있습니다.
T
번역 중페이지를 번역하고 있습니다.
T
사용 중번역이 완료되어 표시 중입니다.
T
오류번역 또는 모델 상태를 확인해야 합니다.

번역을 끄려면 활성 아이콘을 다시 클릭하세요. 사이트 자동 번역으로 시작된 페이지도 같은 방법으로 현재 번역을 끌 수 있습니다.

번역되는 내용

Translight는 문단, 제목, 목록, 인용문, 캡션, 표 셀처럼 읽는 데 필요한 본문 요소를 번역합니다. 코드 블록, 서식 있는 코드, 입력창과 버튼은 원래 상태로 남겨 둡니다.
