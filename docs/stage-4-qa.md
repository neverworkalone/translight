# Stage 4 출시 전 QA

## 자동 검증

```bash
npm run check
```

자동 테스트는 DOM 수집·표 셀 삽입·세 번역 모드·열 가지 표시 스타일·동적 변경·취소·실패 복구·설정 round-trip을 확인합니다.

## Chrome 수동 매트릭스

각 항목에서 번역 시작 → 모델 상태 확인 → 해제 → 다시 시작 순서로 확인합니다.

| 대상 | 확인 내용 |
| --- | --- |
| 일반 기사·긴 블로그 | 제목, 문단, 목록, 인용문, 캡션의 위치와 원문 복구 |
| 제목·목록·인용문 혼합 | 번역문 삽입 위치와 중첩 구조 유지 |
| 중첩 `div` 사이트 | 부모·자식 번역 중복 및 레이아웃 손상 없음 |
| 표 | `td`·`th` 안에 번역문이 생기고 행·열 구조 유지 |
| 기술 문서 | 본문은 번역하고 `code`·`pre`는 원문 유지 |
| SPA·같은 사이트 이동 | hash/history 이동 후 언어 재판정 및 중복 없음 |
| 무한 스크롤·실시간 변경 | 새 subtree와 변경 텍스트의 지연 번역 |
| 매우 긴 페이지 | 화면 우선 번역, 스크롤 후 누락 없이 진행 |

## 상태·설정 매트릭스

- 모델 상태: Downloadable, Downloading, Available, Download Failed, Unavailable
- 번역 모드: 원문+번역문, 번역문+원문, 번역문만
- 표시 스타일: 10종 모두 선택 후 저장·새 페이지 반영
- 설정: 저장, 다른 설정 페이지 이동 중 draft 유지, 내보내기·가져오기·초기화

## Lifecycle·접근성

- 번역 중 해제, 새로고침, 탭 종료에서 원문과 제목 복구
- 실패한 번역의 늦은 결과가 다시 DOM에 들어오지 않음
- 설정 토글·select·파일 버튼을 키보드만으로 조작하고 focus 표시 확인
- Observer, timer, Translator가 반복 시작·해제 후 남지 않는지 확인

Shadow DOM은 현재 출시 버전에서 지원하지 않습니다. 일반 DOM 바깥으로 순회하지 않고, 페이지 원문을 손상시키지 않은 채 건너뜁니다.
